# PreisScanner für iPhone

## Was die App kann
- Barcode mit der iPhone-Kamera scannen
- Produkt und Preis anzeigen
- Preis ändern
- Produkte hinzufügen und löschen
- Daten lokal im Browser speichern

## Auf dem iPhone
Die Kamera benötigt HTTPS. Am einfachsten ist GitHub Pages:
1. Erstelle auf GitHub ein neues Repository.
2. Lade `index.html` und `manifest.webmanifest` hoch.
3. Aktiviere unter Settings -> Pages die Veröffentlichung über den `main`-Branch.
4. Öffne die erzeugte HTTPS-Adresse in Safari.
5. Safari -> Teilen -> Zum Home-Bildschirm.
6. Kamera-Zugriff erlauben.

Hinweis: Die Produktdaten werden lokal auf dem Gerät gespeichert. Wenn Safari-Daten gelöscht werden oder die App auf einem anderen Gerät geöffnet wird, sind die Daten nicht automatisch dort vorhanden.
